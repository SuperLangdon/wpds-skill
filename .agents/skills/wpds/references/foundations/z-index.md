# Z-index

| Name | Value | Description |
| --- | --- | --- |
| `$offer` | `400` | This layer is reserved only for offers like paywalls, overlays etc |
| `$shell` | `300` | This layer is reserved for shell items like the fixed primary nav |
| `$ads` | `200` | This layer is reserved for ads not on page |
| `$page` | `100` | Any content that is on that main page |
